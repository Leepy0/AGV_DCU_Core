# 추가 제안 목록

요구된 기능(파라미터 조정, I/O 모니터·제어, 조그, 변위 이동, 목적지 지령, 태그 시험) 외에 리팩토링과 함께 넣을 만한 것. 우선순위: A = 코어 첫 릴리스에 포함 권장, B = 다음 릴리스, C = 별도 과제.

## 1. 안전·진단

| # | 제안 | 내용 | 우선 |
|---|---|---|---|
| 1 | 가이드센서 통신 두절 검출 | 응답 타임아웃·체크섬 연속 실패 → 255 → 정지 | A (결함 수정) |
| 2 | 엔코더 고착·단선 검출 | 지령 충분·한쪽만 N틱 무펄스. 램프 구간 제외. `P_ENC_STALL_TICKS` | B |
| 3 | 10 ms 초과 카운터 | `overrun_cnt`, 최대 소요 시간 기록. 관리 프로토콜 조회 | A |
| 4 | 워치독 리셋 원인 기록 | 부팅 시 리셋 원인 레지스터를 로그에 | A |
| 5 | 블랙박스 | 오류 발생 시 직전 5초(50샘플) 상태 스냅샷 고정 저장 | B |
| 6 | 이벤트 로그 링 버퍼 | (시각, 코드, 인자 2개) 256건. 전원 유지 안 함. `LG`로 회수 | A |
| 7 | 정지 정확도 로그 | 위치 정지 완료 시 잔여 펄스 기록 | A |
| 8 | 앰프 오류 리셋 이력 | 200/201 자동 리셋 횟수. 반복 시 알람 | B |
| 9 | 배터리 추세 | 전압 1분 평균 링 버퍼, 저전압 예측 | C |
| 10 | 자가 진단 모드 | 정지 상태에서 출력 순차 토글·입력 에코·엔코더·DAC 확인. 설치 검수용 | B |
