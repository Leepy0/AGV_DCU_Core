# 게이트웨이 연동 기능과 관리 프로토콜

요구: 게이트웨이 서버에서 AGV별 파라미터 조정, 입출력 상태 모니터·제어, 조그 이동, 특정 변위 이동, 목적지 지령, 태그 동작 시험. 현재 게이트웨이(v0.7.1)에는 이 기능이 없고 브릿지·DCU에도 규격이 없다(`AGV_DCU_App/analysis/interface_report.md` 3절). 이 문서가 DCU 쪽 규격을 정한다. 게이트웨이 화면·API는 별도 과제다.

## 1. 안전 규칙 (모든 원격 명령에 공통)

| 규칙 | 내용 |
|---|---|
| 모드 | 조그·변위 이동·출력 강제·태그 시험은 `UI_REMOTE` 모드에서만. 모드 진입은 정지 상태(`Flag_run==OFF`, `vin_out==0`)에서만 허용. 진입하면 ACS 보고 송신은 상태 프레임만 남기고 멈춘다 |
| 데드맨 | 조그·변위 이동은 500 ms 안에 다음 명령(또는 유지 명령)이 없으면 `stop_request_rapid(COMMAND)` |
| 우선순위 | E-STOP, 범퍼, STOP 스위치, 앰프 오류는 원격 명령보다 항상 우선. 원격 명령이 이것을 해제하지 못한다 |
| 출력 강제 | 앰프 제어 출력(`OUT_AMP_*`)은 강제 불가. 강제는 시간 제한(최대 10 s) 뒤 자동 해제 |
| 링크 | 주행 영향 명령(조그·변위·출력 강제·태그 시험)은 `P_COMM_LINK==1`(WiFi) 또는 USB/BLE 브릿지에서만 수락. 지그비에서는 `NG 링크` 응답 |
| 인증 | 세션 토큰(2바이트 난수, `SESSION_OPEN` 응답)을 모든 주행 영향 명령에 포함. 토큰은 모드 이탈·30 s 무통신 시 무효 |
| 기록 | 모든 쓰기 명령은 로그 링 버퍼에 (시각, CMD, 인자) 기록 |

## 2. 명령 표 (`M` 프레임, `04_통신_계층.md` 6절)

| CMD | 이름 | 요청 페이로드 | 응답 페이로드 | 모드 |
|---|---|---|---|---|
| `ID` | 식별 | 없음 | 앱 버전 8, 코어 버전 8, 사이트 코드 4, 프로파일 2, git 해시 8, 빌드일 8 | 모두 |
| `ST` | 상태 조회 | 없음 | 2.1절 상태 블록 | 모두 |
| `SP` | 주기 상태 켜기 | 주기(100 ms 단위, 0 = 끔) | OK | 모두 |
| `PR` | 파라미터 읽기 | 시작 idx, 개수(≤ 16) | idx별 값(int16) | 모두 |
| `PW` | 파라미터 쓰기 | idx, 값 | OK / NG(한계 위반, 주행 중 불가 항목) | 정지 |
| `PS` | 파라미터 저장 | 없음 | OK (EEPROM 큐에 넣고 완료 뒤 응답) | 정지 |
| `PL` | 한계값 읽기 | idx | 하한, 상한, 자릿수 모드 | 모두 |
| `PD` | 기본값 복원 | 종류(-1/-2/-3) | OK | 정지 |
| `IR` | 입력 읽기 | 없음 | 논리 입력 비트맵 64비트 + 물리 버스 원시값 6바이트 | 모두 |
| `OR` | 출력 읽기 | 없음 | 논리 출력 비트맵 64비트 + 강제 마스크 | 모두 |
| `OF` | 출력 강제 | 토큰, 출력 ID, 값, 유지 ms(≤ 10000) | OK/NG | REMOTE |
| `OC` | 강제 해제 | 토큰, 출력 ID(0xFF = 전부) | OK | REMOTE |
| `SO` | 세션 열기 | 요청 모드(REMOTE) | 토큰 / NG(사유) | 정지 |
| `SC` | 세션 닫기 | 토큰 | OK | REMOTE |
| `JG` | 조그 | 토큰, 방향(전/후/좌회전/우회전/정지), 속도 m/min(≤ P_SPEED_JOG) | OK | REMOTE |
| `JK` | 조그 유지 | 토큰 | OK | REMOTE |
| `MV` | 변위 이동 | 토큰, 방향, 거리 mm(≤ 5000), 속도 m/min | OK + 이동 ID | REMOTE |
| `MQ` | 변위 이동 상태 | 이동 ID | 단계, 남은 mm, 완료/실패 | REMOTE |
| `DS` | 목적지 지령 | 스테이션 3개 | OK | AUTO |
| `TT` | 태그 시험 | 토큰, 태그 번호 | OK + 실행된 액션 목록 | REMOTE 또는 AUTO 정지 |
| `TR` | 태그 규칙 조회 | 태그 번호 | 규칙 텍스트(액션 코드 열) | 모두 |
| `SQ` | 시퀀스 시험 | 토큰, 시퀀스 ID | OK | REMOTE |
| `AC` | ACT 시험 | 토큰, ACT ID | OK | REMOTE |
| `ER` | 오류 조회 | 없음 | system/stop/action 코드 + 최근 10건 | 모두 |
| `EC` | 오류 해제 | 없음 | OK (STOP 스위치와 같은 처리) | 정지 |
| `LG` | 로그 읽기 | 시작 순번, 개수 | 레코드 열 | 모두 |
| `CS` | 통신 통계 | 없음 | 송신·재전송·포기·수신 오류·ACK 지연 | 모두 |
| `RB` | 재부팅 | 토큰 | OK 후 워치독 리셋 | 정지 |
| `KR`/`KW` | KEEP 읽기/쓰기 | addr(, 값) | 값 | 정지(쓰기) |

응답 `NG` 사유 코드: 01 주행 중, 02 모드 아님, 03 토큰 불일치, 04 한계 위반, 05 링크 불허, 06 안전 입력 활성, 07 인자 오류, 09 기타.

### 2.1 상태 블록 (`ST`, 주기 상태)

| 필드 | 크기 | 내용 |
|---|---|---|
| 모드 | 1 | UI 모드, 런 모드, 주행 단계 |
| 속도 | 4 | `vin_out`, 좌·우 rpm |
| 위치 | 6 | `Total_length`, 남은 정지 펄스, 가이드 편차 |
| 오류 | 3 | system/stop/action |
| 입력 | 8 | 논리 입력 비트맵 |
| 출력 | 8 | 논리 출력 비트맵 |
| ACS | 4 | 활성 슬롯 수, 교차로 상태, 스테이션 큐 길이, 최근 태그 |
| 배터리 | 2 | 0.1 V, % |

ASCII-HEX로 약 80자. WiFi 생존 신호 겸용(2초 주기).

## 3. 기능별 DCU 구현

### 3.1 파라미터 조정

- `param_set(idx, v)`가 한계 검사·파생값 재계산을 한다. 원격 쓰기는 같은 함수를 쓴다. 키패드 편집과 동일 경로.
- 주행 중 변경 금지 항목: 휠·기어·휠베이스·AGV ID·AGV TYPE·통신 링크·보레이트. 나머지는 정지 상태에서만 허용(단순화를 위해 전부 정지 조건).
- `PW`는 RAM만 바꾼다. `PS`가 EEPROM 저장. 저장 전 재부팅하면 되돌아간다(키패드 동작과 같음).
- 한계값·이름·단위는 코어 헤더의 표를 그대로 게이트웨이에 복사한다(CSV 내보내기 도구 `tools/param_table.py`).

### 3.2 입출력 모니터·제어

- 논리 입력 64비트, 논리 출력 64비트. 사이트 별칭은 게이트웨이가 `io_map` CSV로 받아 이름을 붙인다.
- 출력 강제는 `io_force(id, v, ms)`가 강제 마스크를 세우고 `io_write()`가 마스크된 비트를 강제값으로 덮는다. 시간이 다 되면 자동 해제. REMOTE 모드 이탈 시 전부 해제.

### 3.3 조그

- 기존 키패드 조그(`jog_process`)와 같은 경로. `JG`는 `Remocon_jog_Flag`에 해당하는 내부 요청을 세우고, `JK`가 500 ms마다 갱신하지 않으면 정지.
- 속도는 `P_SPEED_JOG` 이하. 좌·우회전은 제자리 회전(`Driving_Forward_Backward(2|3)`).

### 3.4 변위 이동

- MotorStop 위치 정지를 그대로 쓴다: `gCnt_stop_lenght = mm × gOne_Length_Pulse`, `Flag_stopping=ON`, `MotorStop_RequestTag()`, 목표 속도 = 요청 속도. 즉 "거리 N의 태그 정지"와 같다.
- 가이드 추종 여부를 인자로: 테이프 위(조향 ON) 또는 테이프 없이 직진(조향 OFF, 좌우 동일 지령).
- 완료는 `MotorStop` COMPLETE, 실패는 FAILED(277). `MQ`로 조회, 주기 상태에도 포함.

### 3.5 목적지 지령

- ACS `N` 프레임과 같은 처리기를 호출한다(스테이션 3개 → 큐 → `DA_ACS_Next` → 재출발). 새 코드가 아니라 입구만 추가.
- AUTO 모드에서만. 이미 ACS가 붙은 현장에서는 게이트웨이가 ACS와 충돌하지 않도록 서버 쪽에서 막는다(서버 정책).

### 3.6 태그 동작 시험

- 기존 `DA_Tag_Num` 주입(`DA_Tag_Number_Input`)과 같은 경로. `TT`는 정지 상태에서 태그 규칙을 실행하고 실행된 액션 목록을 돌려준다.
- "건식 실행" 플래그: 실행하지 않고 어떤 액션이 걸릴지만 반환(`TR`과 결합). 테이블 기반 태그 규칙이면 액션 열거가 바로 나온다.
- 시퀀스 시험 `SQ`: 시퀀스 ID를 직접 요청해 로딩 동작을 정지 상태에서 돌린다. 현장 설치 시 I/O 배선 확인용.

## 4. 게이트웨이 쪽 과제 (이 저장소 밖)

| 항목 | 내용 |
|---|---|
| `M` 프레임 허용 | `AgvFrame.IsForAcs`에서 `M`을 서버 소비로 분류, 수동 전송 종류 검증에 `M` 추가 |
| 화면 | AGV 상세: 파라미터 표(이름·값·한계·단위, 편집·저장), I/O 패널(입력 램프, 출력 토글·강제), 조그 패드(누르는 동안 `JK` 반복), 변위 이동 폼, 목적지 폼, 태그 시험 폼(번호 → 규칙 미리보기 → 실행), 오류·로그·통신 통계 |
| 주기 상태 | `SP`로 켠 상태 프레임을 UDP MAIN_UP으로 받아 호기 현황에 반영 |
| 권한 | 주행 영향 명령은 운용자 확인창 + 서버 감사 로그 |
| 사이트 표 | 앱 저장소의 `io_map.csv`, `param_table.csv`, `tag_table.csv`를 서버가 읽어 이름 표시 |

## 5. 추가 제안 (게이트웨이 연동)

`08_추가_제안_목록.md`에 통합 수록. 이 절은 게이트웨이 관련 항목만 요약한다.

- 블랙박스: 오류 발생 시 직전 5초 상태를 링 버퍼에서 고정 저장, `LG`로 회수.
- 정지 정확도 통계: 위치 정지 완료 시 잔여 펄스를 로그, 서버가 호기별 분포 표시.
- 가이드센서 건강도: 편차 RMS·타임아웃 횟수 추세.
- 통신 품질: 재전송률·ACK 지연을 호기·구역별로.
- 파라미터 프로파일: 서버가 사이트 표준 파라미터 세트를 보관하고 호기별 차이를 표시, 일괄 적용.
- 시각 동기: 브릿지 TIME_SYNC(0x22/0x23)를 DCU 로그 시각에 반영(`M` 명령 `TM`).
- 원격 모드 표시: `UI_REMOTE` 진입 시 탑램프 노랑 점멸·7seg `rE`.
